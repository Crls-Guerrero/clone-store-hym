# Tienda H&M

Aplicación Full Stack desarrollada con React, Spring Boot y SQL Server.

## Tecnologías

- React
- Vite
- Tailwind CSS
- Node.js 22+
- Java 21
- Maven
- Spring Boot
- Spring Data JPA
- SQL Server

## Frontend

```bash
cd frontend
npm install
npm run dev
servidor: http://localhost:5173
```

## Backend

```bash
cd backend-tiendahym
mvn spring-boot:run
servidor: http://localhost:8080
```
